## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Export route as GPX..." (F5 key shortcut) |
| Empty state heading | N/A (not applicable - visualization requires computed route) |
| Empty state body | N/A (not applicable - no empty state for route display) |
| Error state | "No route computed. Select start and end points first to generate a route." or "Failed to write GPX file. Check permissions and try a different location." |
| Destructive confirmation | N/A (not applicable - no destructive actions in this phase) |

**GPX Export Behavior (CLAUDE DISCRETION):**
- Success message: Show simple confirmation dialog: "Route exported successfully to {filename}.gpx"
- Coordinate format: WGS84 decimal degrees with 6 decimal places (≈0.1 meter precision)
- Filename suggestion: `route_{YYYY-MM-DD}.gpx` (auto-generated, can override in dialog)
- File encoding: UTF-8 (standard for GPX 1.1)

**Error Handling (CLAUDE DISCRETION):**
- No route computed: Display warning dialog "No route computed. Select start and end points first to generate a route."
- File write error: Display warning dialog "Failed to write GPX file. Check permissions and try a different location."
- Cancel in dialog: User cancels file save dialog, no action taken (no error message needed)
