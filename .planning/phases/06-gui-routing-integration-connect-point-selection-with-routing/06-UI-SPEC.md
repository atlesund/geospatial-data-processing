## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | black (#000000) | Canvas background (default) |
| Secondary (30%) | N/A | No secondary surface colors in canvas |
| Accent (10%) | N/A | Not applicable — canvas uses semantic colors for data elements |
| Destructive | N/A | Not applicable — no destructive UI elements |

**Semantic Color Mapping (Canvas Elements):**

| Semantic Role | Hex Value | Usage |
|---------------|-----------|-------|
| Start point marker | red (#FF0000) | First click in route selection (`tag='selected_start'`) |
| End point marker | blue (#0000FF) | Second click in route selection (`tag='selected_end'`) |
| Route polyline | orange (#FFA500) | Computed path connecting start and end points (width=3px) |
| Default point marker | white (#FFFFFF) | Standard point rendering |
| Text labels | white (#FFFFFF) | Coordinate display labels (`tag='coord_display'`) |
| Cursor (computation) | watch | OS default cursor during route computation |
| Cursor (selection) | tcross | Crosshair cursor during route point selection |

**Source:** Screen class in `screen_2026.py` lines 150, 162, 432.

Accent reserved for: N/A — color is used semantically to distinguish data elements (start vs end points, route geometry).

**Error Messages (via `utilities.warning()`):**

| Scenario | Message |
|----------|---------|
| Both points not selected | "Both start and end points must be selected" |
| Routing network not loaded | "Routing network not loaded. Load network data first." |
| No world file loaded | "No world file loaded. Load an image with world file (F5)." |
| Routing network empty | "Routing network is empty. Load trail or terrain data first." |
| Coordinate transform failed | "Failed to transform screen coordinates: {error}" |
| Coordinate systems undefined | "Coordinate systems undefined" |
| Coordinate system mismatch | "Coordinate system mismatch: {error}" |
| Near node lookup failed | "Failed to find nearest nodes in routing network" |
| No path found | "No path found between selected points.\nAre points in disconnected network components?" |
| Path computation failed | "Path computation failed: {error}" |
| Empty route path | "Route computation produced empty path" |
| Route transform to screen failed | "Failed to transform route to screen coordinates" |
