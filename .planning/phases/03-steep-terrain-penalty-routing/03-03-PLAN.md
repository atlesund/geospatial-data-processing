<objective>
Integrate terrain weight calculation into terrain mesh generation, replacing uniform edge weights with slope-based penalties.

Purpose: Phase 2 created terrain_mesh_from_raster() with placeholder weights (edge_weight = mesh_spacing). Plan 02 implemented calculate_terrain_weight() function with slope penalties. This plan integrates the two by retrieving elevations during mesh generation and computing terrain-aware weights. The result is a routing network that naturally avoids steep terrain segments.

Output: Modified terrain_mesh_from_raster() function that:
1. Queries raster.get_elevation_at() for each node's elevation
2. Stores elevation in node coordinates or cache for efficient lookup
3. Calls calculate_terrain_weight(elev1, elev2, edge_length) for each edge
4. Stores slope_angle and penalty_factor as edge attributes
5. Uses computed weight = distance × penalty_factor instead of uniform mesh_spacing
</objective>

Current terrain_mesh_from_raster() implementation:

```python
def terrain_mesh_from_raster(raster, mesh_spacing=100, bbox=None):
    routing_net = RoutingNetwork()
    routing_net.epsg = raster.epsg

    world_file = raster._world_file
    pixel_width = world_file[0]
    pixel_height = world_file[3]
    pixel_spacing = mesh_spacing / abs(pixel_width)

    node_id_counter = 0
    rows, cols = raster.shape

    nodes_per_row = 0
    for col in range(0, cols, int(pixel_spacing)):
        nodes_per_row += 1

    for row in range(0, rows, int(pixel_spacing)):
        col_index = 0
        for col in range(0, cols, int(pixel_spacing)):
            # Convert pixel to world coordinates
            x = world_file[4] + col * pixel_width + row * world_file[1]
            y = world_file[5] + row * pixel_height + col * world_file[2]

            # Add node to routing network
            routing_net.add_node(node_id_counter, x, y)

            # Connect to left neighbor (same row, previous column)
            if col_index > 0:
                left_id = node_id_counter - 1
                edge_weight = mesh_spacing  # ← REPLACE THIS
                routing_net.add_edge(node_id_counter, left_id, edge_weight,
                                   length=edge_weight,
                                   source='terrain')

            # Connect to top neighbor (previous row, same column)
            if row > 0:
                top_id = node_id_counter - nodes_per_row
                edge_weight = mesh_spacing  # ← REPLACE THIS
                routing_net.add_edge(node_id_counter, top_id, edge_weight,
                                   length=edge_weight,
                                   source='terrain')

            node_id_counter += 1
            col_index += 1

    return routing_net
```
