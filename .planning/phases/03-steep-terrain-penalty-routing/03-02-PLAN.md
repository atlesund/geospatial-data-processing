## Locked Decisions (from 03-CONTEXT.md)
**D-01**: Use slope = elevation_diff / raster_pixel_spacing. Compute slope directly from elevation differences between mesh nodes.

**D-02**: Slope calculation applies per mesh edge. For each edge, compute elevation difference between two endpoint nodes, divide by edge length (matches mesh_spacing), convert to degrees: slope_angle = atan(elevation_diff / horizontal_distance).

**D-03**: Penalty applies when slope > 20 degrees. Below or equal to 20°, no penalty.

**D-04**: 20° chosen as aggressive threshold. Allows moderately steep terrain while avoiding unrealistic vertical climbs.

**D-05**: Linear scaling. Penalty_factor = 1.0 for slope ≤ 20°. For slope > 20°, penalty_factor = 1.0 + k × (slope - 20°) where k = 0.2. Creates smooth gradients:
  - 25° slope: penalty_factor = 2.0 (2× harder)
  - 35° slope: penalty_factor = 4.0 (4× harder)
  - 45° slope: penalty_factor = 6.0 (6× harder)

**D-06**: Multiplicative. Final weight = distance × penalty_factor. Applies per edge, not per whole route.

**D-07**: Continue with Dijkstra on updated weights (Plan 04 implementation).
