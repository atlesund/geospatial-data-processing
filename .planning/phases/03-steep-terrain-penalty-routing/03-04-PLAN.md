```python
def shortest_path(self, source, target):
    """
    Compute shortest path between two nodes using Dijkstra algorithm.
    """
    path = nx.dijkstra_path(self.graph, source, target, weight='weight')
    return path
```

NetworkX automatically reads 'weight' attribute from edges. Plans 02-03 set edge weights to terrain_weight = distance × penalty_factor. No modification needed.

## Integration Point
Dijkstra automatically uses updated edge weights because:
1. Plan 03 sets weight=terrain_weight (from calculate_terrain_weight)
2. NetworkX reads 'weight' attribute during graph traversal
3. shortest_path() calls nx.dijkstra_path(self.graph, source, target, weight='weight')
4. Pathfinding minimizes sum of edge weights, avoiding high-penalty edges
